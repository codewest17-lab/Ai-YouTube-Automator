Add these lines to the `dependencies { ... }` block in
android/app/build.gradle (generated by `npx cap add android`):

    implementation "androidx.work:work-runtime:2.9.1"
    implementation "androidx.core:core:1.13.1"

Also make sure android/app/build.gradle's `android { defaultConfig { ... } }`
targets at least:

    minSdkVersion 26
    targetSdkVersion 34

(Android 8.0+ is required for the foreground service + notification channel
APIs used by FolderWatchService and VideoUploadWorker.)
